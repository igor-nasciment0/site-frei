# About

This frontend application was built for **[Instituto Social Nossa Senhora de Fátima](https://acaonsfatima.org.br)**, where I studied in 2023. It served as the live platform for new student admissions between October and November 2025.

## Tech Stack & Requirements

* **Framework:** React + Vite
* **Prerequisites:** Requires the Institute's backend REST API and the necessary environment variables/API keys configured to function.
